# Islamic Occasion Planner

A lightweight Flutter Android app for planning Islamic occasions, reminders, budgets, and savings.

## Purpose
The app helps users prepare before important Islamic occasions instead of remembering expenses only when the occasion is already near.

## Core Features
- Gregorian + Hijri date
- upcoming Islamic occasions
- manual Hijri adjustment
- local notifications
- custom occasions
- budget categories
- savings tracker
- required daily/weekly/monthly saving
- yearly expense forecast
- local backup/restore
- offline-first
